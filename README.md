# Paradise Nursery

## Project Name
Paradise Nursery — Online Plant Shopping Application

## Project Description
Paradise Nursery is a plant shopping web application where users can explore different categories of plants, view plant images and prices, add plants to their shopping cart, update quantities, and calculate their total purchase amount.

## Features
- Browse plants organized by category.
- View plant images, names, and prices.
- Add plants to the shopping cart.
- Increase or decrease item quantities.
- Remove items from the cart.
- View the total number of items and total cart amount.
- Navigate between the Home, Plants, and Cart pages.

## Technologies Used
- React
- JavaScript
- Redux Toolkit
- CSS
- Vite

## Project Purpose
The purpose of this project is to demonstrate the development of a plant shopping application using React components, state management with Redux Toolkit, and responsive user interface styling.
